LUNÉ — демосайт студии красоты. Файлы готовы для GitHub и Timeweb Cloud.
Загружайте в корень нового репозитория ВСЕ файлы этого каталога:
index.html, style.css, script.js, favicon.svg, assets/.

В Timeweb Cloud: App Platform → создать Frontend → HTML/CSS/JS → ваш GitHub-репозиторий → ветка main → корень репозитория. Команда сборки не нужна.

ВАЖНО: сайт демонстрационный: контакты, адрес, цены и отзывы не являются реальными. Ссылку YCLIENTS пока не подключали. Иллюстрации включены в папку assets; внешних изображений и шрифтов нет.

Для масштабируемого генератора скачайте отдельный архив lune_beauty_scalable_source.zip.
