LUNÉ — статический сайт студии красоты. Для GitHub Pages или Timeweb разместите index.html, style.css, script.js, favicon.svg и assets/ в корне сайта. Сборка не требуется.

Контент
Каждая процедура описана один раз в index.html в блоке article.service-card. Укажите название, описание, изображение и цену. Выбор находится в самих карточках. У каждой карточки свой id для ссылок из портфолио. Для изменения галереи редактируйте .work-example. Основные цвета задаются переменными --paper, --ink, --wine и --gold в style.css.
Цены перенесены из исходного макета и требуют подтверждения владельца перед публикацией. Подбор процедуры работает локально и не отправляет заявку. Подтверждённых контактов, ссылок на запись и отзывов на момент подготовки нет.
